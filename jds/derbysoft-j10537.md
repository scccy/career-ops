# 高级数据工程师-数仓&数据治理 (J10537)

## 工作职责

我们正在建设面向全球业务的数据底座与统一数据语义层。该岗位不是单纯的报表取数或离线脚本开发，而是负责把业务事实沉淀为可追溯、可复用、可验证的数据资产，并持续提升数据链路的时效性、稳定性与治理水平。

### 岗位职责
- 数仓建模与数据重构：负责企业级数仓模型设计与持续演进，运用维度建模、分层建模等方法，清晰定义数据粒度、主键、口径、生命周期与依赖关系；主导存量链路和数据模型的重构、整合与治理。
- 数据链路建设与交付：规划并建设覆盖离线、实时和准实时场景的数据采集、加工、调度与服务链路；持续优化数据处理性能、资源成本、运行效率。
- 数据质量与治理体系：建立并完善数据质量、数据标准、元数据、数据血缘、指标字典和权限管理体系。
- 数据资产赋能与工程规范：沉淀标准数据资产与语义能力；推动研发规范、模型评审、代码评审、测试发布、文档沉淀及 AI 等工具辅助研发。

### 任职资格
- 5年及以上数据仓库、大数据或数据工程开发经验；精通 SQL 和 Python，熟悉 Airflow、Spark、Hive、Iceberg、StarRocks 等主流数据工程技术与湖仓实践。
- 具备 Kafka、Flink 或同类流处理框架的实战经验。
- 熟悉维度建模，深刻理解数据质量、元数据、血缘与指标治理。
- 熟悉 Git 和团队协作流程，具备代码评审、故障恢复及性能优化意识。
- 具备良好的英文读写和沟通能力。
- 具备 AI 实践能力：LLM、RAG、Agent / Tool Calling、智能数据开发辅助、元数据问答、质量异常排查。
