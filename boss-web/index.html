💾 候选池存储 MySQL

全量候选已切到 career_ops.boss_jobs（Docker MySQL 8.0，仅绑 127.0.0.1）。

扫描写入、评分/排队读取、发送后把 greeted 置 1；data/boss-candidates.json 降级为写池时的备份镜像，库空时一次性迁移。

key_hash CHAR(64) 主键 url / greeted 独立列 score DECIMAL(4,2) idx_city_score

🎯 点名单发 key_hash

boss:send:one --key-hash <h1[,h2,…]>

单个或多个 key_hash 都支持（逗号/空格分隔），按 boss_jobs.key_hash 直取，绕过队列/城市配额/30 天去重；greeted=1 默认拒绝重发，需 --force-greeted。

流程不变：先 --dry-run 展示岗位+文案 → 你明确确认 → 再加 --confirmed-review。

key_hash 点名查询（单 / 多个）

key_hash 由 SQL 查得，如 SELECT key_hash,company,title,score FROM boss_jobs WHERE city='杭州' AND greeted=0 AND score>=3.5 ORDER BY score DESC。本面板只做查询/预览，真实发送仍需你在对话中确认后由脚本执行。
