流程③评分只跑一轮 LLM：把 cv.md + 这一批岗位的 JD 一起发过去，每个岗位返回「匹配结构 + 招呼语」（资历/外包/技术栈/红线/匹配分/文案一起回来）。数量上只有一个参数——每批岗位数；批次数 = 待处理岗位数 ÷ 每批岗位数，日志会直接写「待处理 N 条 ÷ 每批 M = K 次请求」。输出预算与超时按批自动推算，不用填。失败、超时、返回空一律回落内置模板文案，绝不留空招呼语；报告与 boss_jobs.raw.greetingSource 如实标注来源（llm = 本次生成 / llm_analysis = 历史解析复用 / template = 模板兜底）。Key 存在 PostgreSQL（页面只显示掩码），但控制台无鉴权 —— 绑到 0.0.0.0 时同网段任何设备都能改这里。
