## 模块概览

```text
数据平台
  ├─ 开发规范    — 数据库设计 / API 设计 / 服务开发 等通用规范
  ├─ 页面设计  — 整体页面布局、Tag 切换 (看板/分析/设置)
  ├─ 看板      — 看板管理、项目空间、共享、筛选、组件
  ├─ 分析      — 事件分析、漏斗分析、留存分析、分布分析、属性分析
  ├─ 用户      — 用户分群、用户细查
  ├─ 数据      — 元事件管理、属性管理、实时数据、数据表
  ├─ 设置      — 用量概览
  └─ 权限      — 系统角色、数据权限、资源权限
```
