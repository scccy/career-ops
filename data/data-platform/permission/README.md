## 模块概览

```text
权限（SaaS）
  ├─ 平台侧
  │    ├─ 平台 RBAC（平台管理员 / 运营 / 销售）
  │    ├─ 公司管理
  │    └─ 权限点目录（全局）
  │
  └─ 公司侧
       ├─ 公司 RBAC（基础角色 + 自定义角色）
       ├─ 项目-员工-角色绑定
       ├─ 数据权限（数据权限组 + 员工额外权限）
       └─ 资源权限（平台运营定义，项目管理员分配）
```
