# 权限管理前端页面设计

**日期**: 2026-07-13
**范围**: Auth 模块 SaaS 权限模型 V3.0

---

## 菜单结构

```
人员管理
├── 企业管理
├── 数据权限管理
├── 路由权限管理
├── 资源权限管理
├── 人员管理
├── 角色管理
└── 项目组管理

产品管理（Event 模块，本文档不涉及）
```

## 角色可见性

| 菜单项 | 平台超级管理员 | 平台运营 | 平台销售 | 公司管理员 | 项目管理员 |
|--------|:------------:|:--------:|:--------:|:--------:|:--------:|
| 企业管理 | ✓ | ✓ | ✓ 仅创建 | ✗ | ✗ |
| 数据权限管理 | ✗ | ✗ | ✗ | ✓ | ✓ 仅自己管理的项目 |
| 路由权限管理 | ✓ | ✓ | ✗ | ✗ | ✗ |
| 资源权限管理 | ✓ | ✓ | ✗ | ✗ | ✗ |
| 人员管理 | ✗ | ✗ | ✗ | ✓ | ✓ 仅额外数据权限 |
| 角色管理 | ✗ | ✗ | ✗ | ✓ | ✓ 仅 scope=PROJECT |
| 项目组管理 | ✗ | ✗ | ✗ | ✓ | ✓ 仅自己管理的项目 |

---

## 1. 企业管理

**使用者**: 平台超级管理员 / 平台运营 / 平台销售

**功能**:
- 公司分页列表，支持按名称/编码/状态搜索
- 创建公司（同时创建管理员账号和初始化 4 个基础角色）
- 查看公司详情
- 启用/停用公司（停用会吊销所有员工 token）

---

## 2. 数据权限管理

**使用者**: 公司管理员 / 项目管理员（仅自己管理的项目）

**功能**:
- 数据权限组分页列表，支持按名称搜索
- 创建数据权限组（配置名称、描述、规则列表）

  规则列表每行：资源类型（MINIGAME / PACKAGE / CHANNEL / APP）+ 资源值

- 编辑/删除数据权限组
- 查看数据权限组详情（含规则列表）
- 删除时若被角色引用，提示"请先解除 X 个角色的绑定"

---

## 3. 路由权限管理

**使用者**: 平台运营

**功能**:
- ROUTE 权限点分页列表，支持按编码/名称/作用域/状态/模块搜索
- 编辑权限点信息（名称、模块、作用域、状态）
- Scope 变更：先分析影响范围（受影响公司数、角色数、员工数），再确认执行

---

## 4. 资源权限管理

**使用者**: 平台运营

**功能**:
- FUNCTION 权限点分页列表，支持按编码/名称/作用域/模块搜索
- 创建 FUNCTION 权限点（编码、名称、作用域、模块）
- 编辑/删除 FUNCTION 权限点
- 删除时若被资源权限组引用，提示"请先解除 X 个资源权限组的绑定"

---

## 5. 人员管理

**使用者**: 公司管理员 / 项目管理员（仅额外数据权限）

**功能**:
- 员工分页列表，支持按邮箱/姓名/状态搜索
- 创建员工（复合接口）：基本信息 + 可选分配项目角色 + 可选单条数据权限

  创建时可同时指定：
  - 项目角色列表：每行选项目 + 角色
  - 数据权限列表：每行选项目 + 资源类型 + 资源值

- 编辑员工基本信息（姓名、是否管理员）
- 启用/禁用员工（禁用会吊销该员工所有 token）

**员工额外数据权限**（内嵌在人员管理页面）:
- 按项目/员工查看额外数据权限列表
- 添加额外数据权限（项目 + 员工 + 资源类型 + 资源值）
- 删除额外数据权限

---

## 6. 角色管理

**使用者**: 公司管理员 / 项目管理员（仅 scope=PROJECT）

**功能**:
- 角色分页列表，支持按作用域/项目/关键词搜索
- 创建角色：作用域、项目、编码、名称、描述 + 可选绑定路由权限组 + 可选绑定资源权限组 + 可选绑定数据权限组
- 编辑角色：更新基本信息 + 同时调整路由权限组、资源权限组和数据权限组绑定
- 删除角色（基础角色不可删除，被成员引用时阻止删除）
- 查看角色详情（含已绑定的路由权限组、资源权限组和数据权限组）

**路由权限组管理**（内嵌在角色管理页面）:
- 路由权限组分页列表，支持按名称搜索
- 创建路由权限组：选择 ROUTE 权限点
- 编辑/删除路由权限组
- 查看路由权限组详情

**资源权限组管理**（内嵌在角色管理页面）:
- 资源权限组分页列表，支持按名称搜索
- 创建资源权限组：选择 FUNCTION 权限点
- 编辑/删除资源权限组
- 查看资源权限组详情

---

## 7. 项目组管理

**使用者**: 公司管理员 / 项目管理员（仅自己管理的项目）

**功能**:
- 项目分页列表，支持按名称/状态搜索
- 创建项目：名称、描述 + 可选绑定 appId（SDK 数据源，来自 Event 模块）
- 编辑项目：更新名称、描述 + 同时调整 appId 绑定
- 删除项目（有成员时阻止删除）
- 查看项目详情（含已绑定的 appId 列表）

**项目成员管理**（内嵌在项目组管理页面）:
- 项目成员分页列表，支持按项目/姓名/角色搜索
- 添加成员（选员工 + 选角色）
- 移除成员
- 变更成员角色
